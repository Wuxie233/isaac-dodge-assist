# 以撒紧急躲避 0.12.0

人工移动路径即将进入危险范围且存在更安全方向时，接管本机键盘移动；危险解除后交还控制。当前使用 Lua 0.12.0 传感器与 NativeHost 0.4 原生输入程序，不再使用旧 SendInput 辅助。设计面向仅本机安装的场景，Online 同步效果仍待实测。

## 使用

1. 重启游戏，在 Mods 菜单启用 Isaac Dodge Assist。
2. 打开桌面的“以撒原生输入躲避”（指向 NativeHost 0.4），保留原生辅助窗口；旧“以撒紧急躲弹”辅助应关闭。
3. 确认 HUD 显示 `DODGE v0.12.0`。`450/467ms` 表示设置窗口/实际预测窗口（联机时会加上测得的输入延迟）；HUD 的威胁状态不等同于输入已执行。
4. F6 开关，左 Shift 按住暂停（联机表情占用左 Alt），F8 切换 250 / 350 / 450 / 600ms（默认 450）。多人时用 F7 选择自己的角色；当前原生执行器仅适配本机键盘设备。
5. F9 开关危险预览，F10 切换战斗辅助：关 → 自动瞄准（AIM）→ 自动战斗（AUTO）→ 关。

## 0.12 自动瞄准与自动战斗

`combat.lua` 选目标（最近的可受伤敌人，带切换滞后），按眼泪飞行时间加联机输入延迟提前量，量化到四个射击方向。提前量与弹道通畅规则沿用 [isaac-jev](https://github.com/chongchong59699/isaac-jev)（MIT）的 `localFireDirection` / `clearTearLane`：飞行时间 = 距离 / (ShotSpeed × 10)，限定 1.5～12 次更新。

- AIM：按住任意射击键时，原生程序把方向换成瞄准方向；不按不射。
- AUTO：房间有敌人且你不碰方向键时，原生程序接管走位和射击。站位目标是目标所在行或列、射程 0.8 倍左右、弹道上没有石头（穿透和激光武器忽略石头）、远离其他敌人的点，用格子 BFS 绕障碍走过去。躲避优先：只在当前最安全的风险等级里朝站位走，有实打实的碰撞风险时直接按躲避评分走。按方向键就是手动走（仍有躲避），按射击键就是手动射（自动瞄准）。左 Shift 照常全部释放。
- 蓄力武器（硫磺火、妈刀、肺、Tech X、巧克力奶、诅咒之眼、海王星）：按住蓄力，对准后松开一次；如果松开后没看到攻击出现，就加长蓄力估计，出现了就略缩短。圣剑按一下松一下。

协议：传感器在每个 IAD1 包前写一行 `IAD2|<该包序号>|<word>`（位 0-1 模式，2-5 走位，6-8 射击，9 按住），只在战斗模式开启时输出；NativeHost 0.4 把它写进共享内存原保留字段，旧 Host 忽略。

闭环模拟（`SIM_COMBAT=auto`，敌人有血量、角色发射眼泪、击杀后在边缘重生；8 帧输入排队；0～3 帧额外延迟平均）：完全不碰键盘时约 2.9 次/分钟受伤，与手动乱走加躲避辅助的约 5.4 次相当或更少；击杀约 12（炮台）～19（追击怪）～43（苍蝇群）只/分钟。站位距离从射程 0.45 倍改到 0.8 倍后受伤约减半，击杀基本不变。模拟敌人只有直线子弹和追击，不能代替实机验收。

F9 预览在战斗模式下另画目标圈（青色）、瞄准点（青色十字）和站位点（绿色叉）。

## 0.10.2 联机输入延迟、红便便与子弹高度

0.10.0 首个实机会话在 Online 房间进行，共 26 次伤害回调：红便便 6、敌方子弹 8、怪物与冲刺 4、玩家自身来源 7、诅咒门 1。受伤前 15 次更新的回执显示，实际输入的变化与 4 次更新之前评分对应的原生选择吻合 22/82，其余延迟只有 1～8 次。即联机会把本机输入（手动和原生接管都一样）排队约 4 次更新（约 133ms）后才执行，而规划器按几乎即时生效计算。

`input_queue.lua` 通过被 Hook 的键盘设备读取正在入队的输入（`Input.GetActionValue`），与 `GetMovementInput()` 实际执行的输入比较，按投票确定延迟，离线时保持 0。规划时先用队列中的输入推进角色，再比较各方向，预测窗口自动加上该延迟（上限 22 次更新）。`IAD KIN` 输出 `delay=` 与各延迟的票数，TRACE 增加 `q=`（入队输入）。闭环模拟在 8 帧输入排队下：0.9.2（350ms）约 15.4 次/分钟，0.10.1 约 7.9，0.10.2 约 6.1，接管时间约少三分之一。离线结果不变。

红便便（`DAMAGE_POOP`）完整时按 26 单位静态命中区处理，普通便便与飞行角色除外。两次漏判子弹命中时高度为 -49，旧版只认 -40～0 的碰撞带，现改为 -60～0。

## 0.10 玩家运动模型、接触判定与闭环模拟

0.9.2 实机日志显示，玩家每个 30Hz 逻辑更新的位移约为 `Velocity` 的 2.0 倍，怪物约 1.0 倍；官方文档也注明玩家更新回调每秒 60 次。旧规划器把玩家按每更新一次积分、终速 `6 × MoveSpeed`、阻尼 0.65/0.75 计算，低估了冲向危险时的惯性和实际逃离速度。`player_motion.lua` 改为每更新两个物理帧、每帧保留速度约 0.88、终速约 `4.2 × MoveSpeed`，并在游戏中用 `GetMovementInput()` 与速度变化持续校准；换房和退出时输出 `IAD KIN`。首局 0.10.0 校准收敛到 idle 0.880、drive 0.874、k 4.33。原生输入生效前的延迟内，按当前实际输入继续推演。

接触伤害只把引擎碰撞圆（两者 Size 之和）加 3 单位算作命中；按速度放大的缓冲圈改为预警。旧版把整个缓冲圈当命中，追击怪靠近时九个方向会同时判为“马上撞上”，无法区分好坏路线。

Vis（不含 Chubber）与暴食在 `Attack01Horiz/Down/Up` 前摇时，从第 27 帧起按光束方向预测命中。两次实机记录都在该动作第 28 帧、光束刚出现时受伤，传感器当时仍为 MONITOR。

受伤时新增 `IAD DIAG TRACE`，记录最近 15 次更新的实际输入（含原生接管）、传感器首选方向及其分级（`ok` 安全、`w` 仅预警、`hN` 命中等级），可据此判断接管是否生效。

`native/tests/closed_loop_sim.lua` 用实际 `main.lua`、原生 `rank()` 的 Lua 移植和按上述实测参数运行的房间做闭环模拟，`closed_loop_matrix.py` 汇总 0～3 帧输入延迟与四类场景。同为 350ms 窗口时，旧版平均约 7.6 次/分钟受伤，0.10 约 4.6 次；450ms 约 4.0 次，接管时间占比相近；不开辅助约 32 次。模拟只含直线子弹与追击怪，不能代替实机验收。

## 0.9.2 激光计算与爆炸弹预警

曲线和旋转激光的几何检查改用数值坐标，复用每轮采样线段；只有确定不可能更近的线段才跳过精细计算。保留原采样点、旋转扫掠、预测窗口和两种响应模型。

完整回调压力模拟中，四条直线、曲线、旋转曲线激光的三轮中位耗时分别为 10.65→2.95ms、101.67→3.89ms、425.66→12.16ms。7,600 次几何查询与旧版一致（容差 1e-8），六组场景的全部方向分数与阻挡位一致。这是 Linux Lua 模拟结果，不能换算为实机 FPS。

对带 `EXPLODE` 标志的存活敌方弹体增加 100 单位的保守预警，包括当前处于高空或关闭直接碰撞的弹体；普通弹体、玩家来源、死亡弹体和爆炸烟不会因此增加预警。这个范围不是已核实的爆炸半径，可能提前绕行，精确引爆时机仍未建模。

`IAD PERF` 现在会在换房和退出时输出不足 90 次的剩余样本，短战斗也能留下耗时记录。最新 0.9.1 实机日志有 10,890 次规划样本，平均约 2.66ms、峰值 22ms；部分爆炸伤害发生时传感器仍显示安全。新版增加弹体标志、高度和下落参数的受伤记录，供后续核对。0.9.2 实机效果待加载后验证，详见 [本轮性能记录](native/research/performance-0.9.2.md)。

## 0.9.1 性能修复

0.9.0 的实机日志记录到单次规划耗时 6～14ms。旧测试没有涵盖完整地形查询和对象创建，低估了运行开销。

现在每次更新共享地形缓存，空旷区域直接复用已确认的可通行结果；轨迹计算使用数值坐标，减少临时向量；逃生空间只在风险最低、确实可能被选中的方向之间比较。保留每帧检测、两种响应模型和完整预测窗口，不截断危险物数量。

同一完整回调模拟、三轮各 100 次更新的耗时中位数：单血池 7.15→2.07ms，200 块血池 10.40→4.27ms，30 发弹幕 10.78→4.38ms。这是 Linux Lua 模拟，不是 Windows 帧率测量。新增每 90 次有效规划输出一次的 `IAD PERF`，记录扫描、威胁构建、规划的平均耗时及总耗时峰值，用于后续实机核对。

地形缓存每次更新重建，保留房间边界的精确检查。墙角、L 形房间、飞行与坑洞、障碍变化，以及原有躲避回归检查通过。详见 [性能说明](native/research/performance-0.9.1.md)。

## 0.9.0 算法更新

已经处于血池或敌人危险圈内时，按持续脱离的时间选择路线；窗口内完全出不去时，优先向边界推进。原先所有方向在首帧都危险时，排序容易偏向仍困在另一片血池内的方向。

每个方向同时模拟正常响应和慢一帧、转向更慢的响应，取较差结果。敌人保留短时加速度与匀速两种轨迹假设；减速预测停在零速，避免虚构反向冲刺。碰撞检查覆盖两帧之间的移动路径及子弹高度变化，墙体沿路采样，减少高速穿过细窄危险区域的漏判。

血池等静止区域每轮只建立一次索引，移动威胁按预测时间建立共享索引。九个方向复用这些结果，重叠池按最深危险程度计分，不按实体数量叠加。设置的预判量作为最小窗口，根据角色大小和移速适度延长，上限 600ms。

Lua 语法、主模块回调和针对性场景检查通过，包括墙边血池、快速穿越、连续重规划脱困、通信分数与暂停释放。一次同环境 25 轮局部对比中，600 个区域由旧版九路径约 11.23ms/轮降到新版十八路径约 5.12ms/轮；这是 Linux Lua 模拟，未包含完整游戏与原生通信开销。此次游戏内效果与 FPS 尚待实测。[算法记录](native/research/algorithm-0.9.md) 包含细节。

## 历史变更

以下是各版本当时的规则，冲突处以当前版本和[覆盖记录](COVERAGE.md)为准。

## 0.8.3 修正：攻击动作与停伤时序

乌列、加百列按实际充能动作、状态和发射方向提前避让：乌列向下单束或两条下斜束，加百列正十字或斜十字；散弹、护盾、召唤等动作不再虚构八条激光。发射后交由真实光束检测。

普通与采样激光进入引擎死亡状态后移出危险区；仅 Timeout 归零或开始缩小仍可能伤人，继续避让。白、黑、棕色减速池及滑地不作为扣血危险；血池、绿/黄毒池、静电池进入死亡消退阶段后停止避让。标准伤害池的范围改用引擎采用的 Size 与 SpriteScale，并保留避让余量。

TNT 纳入高伤眼泪、随机额外损伤、酸液/石头泪弹直接毁坏，以及爆炸泪弹撞击周边网格、敌人或普通飞行落地的引爆。普通眼泪伤害大于 10 才跨两阶段；预判包含 TNT 随机多损一阶段的可能，不改变游戏随机数。普通爆炸泪弹按原生落地阈值与垂直运动预测落点，同一眼泪每帧共享预测；悬浮、连锁、胎儿、弹跳等特殊泪弹仍按碰撞来源预警，不套用普通落地公式。

上述规则依据当前安装的 Repentance+ 游戏程序只读核查，配套 Lua 模拟检查通过；游戏内效果待测试。0.8.2 已完成的爆炸余烟排除、无碰撞敌人分离、跳落预警保留。

## 0.8.1 修正：收起的尖刺

普通尖刺和定时尖刺都检查禁用状态；收起动画结束或停在末帧时也移出危险区域，每轮重新读取，升起后恢复检测。修复开关收起尖刺仍触发闪避的问题。

## 0.8 调整：保留逃生空间

在预测伤害风险相同的路线中，优先选择周围连通空间更大、出口更多、敌人更不容易堵住的终点。空间判断包含敌人预测占位及出口通道上的小敌，不按离房间中心的距离硬拉角色。

取消每帧可能不断推迟的“未来第三帧后转弯”假设，按当前真正执行的路线评分，再逐帧重选。即时碰撞风险仍优先于空间；安全时不因为空间分数主动接管。多人辅助继续兼容原通信格式。

每轮共享网格、通道和终点评分，单终点最多探索四格范围（41 个网格），同格结果复用。该算法是有限范围的局部避险，不是全局最优求解；已经完全被围住、存在未识别攻击或速度不足时仍可能受伤。语法、空间场景与评分层次检查已完成，实际脱困效果尚未进行游戏内验收。

## 0.7 调整

天使攻击状态加入提前的八方向光束预警，不等激光出现才开始躲；这是保守包络，并非精确识别每种发射动作，可能在天使其他攻击时提前让路。已出现的激光按完整路径交叉、父实体移动和旋转扫过范围判断。

尖刺纳入伤害评分，收起的开关尖刺不当作危险。爆炸石头的引爆状态、可能被泪弹或附近炸弹引爆的 TNT 纳入提前撤离；TNT 的触发只涵盖这些来源。未爆炸区域与即时伤害分开排序，避免刚放下的炸弹压过眼前子弹。规划增加短直走后转向的候选，但仍不能保证困局无伤。

血池按空间分桶，仅细查路线附近区域；重叠区域每步取最大风险，不按血块数量重复累加。远处到不了的区域先排除；激光扫射、敌人轨迹和房间碰撞读取在每轮计算内缓存复用。没有为了性能截断危险实体数量。0.8.4 起所有模式均保留辅助通信。

本轮做了独立调查/审查和集中模拟检查，未进行游戏内帧率或全敌人实战验收。[覆盖记录](COVERAGE.md) 列出明确缺口；本版不表示全部攻击已经覆盖。

## 0.6 调整

接触敌人改用排除背景 NPC 的分类，商店吊人不再因为 NPC 身份进入接触风险；燃烧篝火仍单独判断。地面毒液不使用 NPC 死亡条件过滤，危险范围计入 SizeMulti 横纵缩放和刹停余量。按长轴取保守圆形包络，可能会比可见毒液范围更早避让。飞行角色忽略这些已识别地面池。

实机日志确认过绿色毒液在监测状态触发伤害回调，但旧日志不含碰撞尺寸和来源归属，无法断言唯一原因；新日志增加这些字段。当前预测覆盖已经出现的毒液，不会读取喷吐动画预知尚未生成的毒液。此更新未完成游戏内验收。

## 0.5 调整

熄灭篝火不再沿用普通敌人的危险圈，仅仍有玩家碰撞伤害的火焰需要避让。快速怪物和子弹加入连续帧速度变化预测，短时外推加速度；减速不外推成反向冲刺。快速怪物按近期速度增加避让余量，避免一停步就立即靠回去。

选路首先避开更早发生的碰撞，再比较危险区内停留程度。路径预测会模拟碰墙停止或沿墙移动，不再因为 350ms 末端碰墙就排除整个方向。仍然按每帧重新决策，不保证来不及逃开的攻击能够躲掉。

| 地面及范围攻击 | 敌方血池/毒池类、火焰、冲击波、落点目标、脚踩/手抓/火箭等常见特效族，以及公开接触伤害的其他特效；按危险圈估计，可能提前或额外避让；飞行忽略已识别的地面池 |
| 爆炸 | 有爆炸伤害的炸弹从出现就避让，包含自己放的炸弹；爆炸余烟不再加入危险圈；TNT 和爆炸岩石单独预警 |

目标是覆盖全部怪物攻击，目前不能声称已经达到。特殊脚本伤害、尚未生成且没有公开预警的攻击、未识别的专用特效，以及 TNT/爆炸怪死亡的精确爆炸时机仍有缺口。这里只调整移动，不取消伤害、不改血量或无敌时间；封死走位的局面仍可能受伤。伤害回调会向游戏日志记录 `IAD HIT` 的来源类型与状态，供定位漏判；其他模组取消的伤害也可能触发此记录，因此它不等同于实际扣血统计。

检测会排除可追溯到玩家、跟班或友方实体的激光与特效。玩家炸弹仍按可能伤到自己处理。方向评分同时检查墙壁、障碍物、坑与尖刺；移动速度、攻击范围和碰撞模型均为近似值。雅各与以扫、遗骸/魂等多实体角色仍显示不支持。

## 安装与卸载

这台电脑已具备 NativeHost 0.2；本次仅更新传感器文件，重启游戏后再打开“以撒原生输入躲避”即可。原生输入程序的构建、支持版本和退出行为见 [native/README.md](native/README.md)。原生 DLL 随游戏退出结束，不修改磁盘上的游戏程序。

根目录 `Install.cmd` / `Install.ps1` 是旧 SendInput 方案安装器，不用于重装当前原生方案。卸载传感器前关闭游戏及辅助，在 PowerShell 运行：

```powershell
& "$env:LOCALAPPDATA\IsaacDodgeAssist\Uninstall.ps1"
```

该脚本按安装记录删除已知传感器和旧辅助文件，保留原生程序目录及其桌面入口。只需停用时，在 Mods 菜单禁用本模组并关闭原生辅助即可。
