# Text and fonts: item names, Options.Language, bundled fonts (Repentance+)

Target: the user's Repentance+ v1.9.7.17.J460 (Windows, `isaac-ng.exe` SHA-256 `210cade2…fb3ae4831`), vanilla Lua only. Researched 2026-11-05.

Labels as in [item-emulation.md](item-emulation.md): **[C]** confirmed in the game binary or data, **[U]** inferred or untested.

## Key conclusions

1. Item names come from the official string table `resources/stringtable.sta` in `afterbirthp.a`. Its "Chinese (Simple)" column (language id 13) has a name for every collectible and trinket. **[C]**
2. `Options.Language` returns `"zh"` for language ids 12 and 13. The user's `options.ini` has `Language=13`. **[C]** (static disassembly; not printed in-game)
3. For Chinese, use `font/cjk/lanapixel.fnt` (line height 13, base 10). It is the game's own CJK replacement for its small HUD font, and it also has full ASCII. **[C]**
4. For English, use `font/luaminioutlined.fnt` (line height 12, ASCII only) or the game's own small HUD font `font/pftempestasevencondensed.fnt` (line height 13). **[C]**
5. LanaPixel covers every character in the item names, but only 3383 of the 3755 common (GB2312 level-1) hanzi. Notably it lacks **帧**. Check new UI strings against `native/tests/data/cjk_font_chars.txt`. **[C]**

## 1. Item names

- **String table.** `afterbirthp.a` → `resources/stringtable.sta` (header `modified="Fri Dec 12 23:36:30 2025" modifiedby="Jerm"`).
  - It is XML with trailing NUL padding.
  - `<languages>` gives the column order, with the key at index 0: English (id 0), Japanese (2), Korean (11), Chinese (Simple) (13), Russian (10), German (5), Spanish (4), French (3). Key = id 21.
  - It has 14 categories and 3151 keys. **[C]**
- **items.xml.** It names entries by key, e.g. `name="#THE_SAD_ONION_NAME"`. Every collectible and trinket key resolves in the `Items` category. **[C]**
- **Coverage.** Generated by `tools/gen_item_names.py` → `mod/isaac_dodge_assist/item_names.lua`. **[C]**
  - 721 collectibles (425 passive, 170 active, 126 familiar; ids 1–732 except 43, 61, 235, 587, 613, 620, 630, 648, 662, 666, 718). All have en and zh.
  - 188 trinkets (1–189 except 47). All have en and zh.
  - The zh name equals the en name only for collectible 15 `<3` and trinket 138 `'M`.
  - Duplicate en names: 34/59 The Book of Belial, 120/121 Odd Mushroom, 550/551 Broken Shovel, 577/656 Damocles.
  - English names are pure ASCII.
- **No string-table API.** Vanilla Rep+ has no Lua binding that reads the string table: no `GetLocalizedString` string in the exe, which is REPENTOGON-only. Hence the generated table. **[C]**
- **The user's Chinese patch.** The install has the workshop mod **CN Patch for Rep+** (`mods/cn_rep+_3568677664`, v2.0.4.4). Its patcher wrote these files into the game folder on 2026-10-11 15:11 (byte-identical, by SHA-256):
  - `resources/packed/repentance_zh.a` = mod `res/repentance_zh.a.copy`.
  - `repentance_de.a` = `res/repentance_emote.a.copy` (redrawn online emotes).
  - `repentance_es.a` = `res/repentance_reveive.a.copy` (redrawn revive machine). The de/es slots are reused; neither archive holds German or Spanish text.
  - `language_unlocker.dll` = `res/inject.bin`. Its internal name is `inject.dll`; strings show `I18nUnlock` and `MinimapTimeLabelFontPatcher`. The mod's `res/config.ini` says `lang=13` (a forced language id), `fixinput=1` (an IME fix), and `check=2119522054` (an exe checksum).
  - `bootstp.dll` (15:08) exports `GetUserProfileDirectoryA` and `ModInit`, and contains the strings `LoadRgon` and `userenv`. It looks like a userenv proxy loader. `isaac-ng.exe` does not import it, and how it is loaded was not traced. **[U]**
- **The patch's string table.** The patch's `repentance_zh.a` carries its own `resources/stringtable.sta` (dated Nov 19 2024, with the same 3151 keys). **[C]**
  - It differs from the official table only outside `Items`: it fills 156 empty zh strings (Default 19, Online 97, RunStatus 40) and makes 2 fixes.
  - The `Items` category is identical, so both tables give the same `item_names.lua` (checked by regenerating from it).
  - Which of the two tables the game loads at runtime is untested. **[U]**

## 2. Options.Language

The Lua property `Options.Language` is registered at 0x86e41d. Its getter is 0x85eee0, which jumps to 0x9547f0. That function reads the language id at `[*0xc7169c + 0x4a920]` and returns the code in the table below. The language id is the same one the string table and `options.ini` use. **[C]**

| id | code | id | code | id | code |
|---|---|---|---|---|---|
| 0, 1 | en | 6 | it | 14 | fi |
| 2 | **ja** | 7 | nl | 15 | sv |
| 3 | fr | 8, 9 | pt | 16 | da |
| 4 | es | 10 | ru | 17 | nn |
| 5 | de | 11 | kr | 18 | pl |
| 12, 13 | **zh** | | | 19 | tr |

Any other id returns `"XX"`.

- **Japanese surprise.** Rep+ reports Japanese as `"ja"`, not the `"jp"` that the installed EID v5.26 expects. EID's `EID.LanguageMap` in `features/eid_language_manager.lua` maps `jp/es/de/fr/ru/kr/zh`. Chinese matches: `zh` → `zh_cn`. **[C]**
- **REPENTOGON.** `main_ex.lua` keys its error text and fonts by `Options.Language` with `"zh"` → `font/cjk/lanapixel.fnt`, and draws lines 12 px apart. Source: TeamREPENTOGON/REPENTOGON `repentogon/resources/scripts/main_ex.lua`, main @225bbad0fe. **[C]**
- **Vanilla scripts.** The vanilla `resources/scripts/main.lua` and `enums.lua` do not use `Options.Language`. **[C]**

## 3. Fonts

**How the game picks its HUD fonts.** The function at 0x95192c switches on the same language id:

| Language | Big font | Small font |
|---|---|---|
| ja | `font/MPlus_12b.fnt` | `font/CJK/LanaPixel.fnt` |
| kr | `font/KR_MeatFont14.fnt` | LanaPixel |
| zh (13) | `font/UpheavalExtended.fnt` | LanaPixel |
| anything else | `font/Upheaval.fnt` | `font/PFTempestaSevenCondensed.fnt` |

So LanaPixel stands in for PFTempestaSevenCondensed in Chinese. **[C]**

The exe also loads:
- `font/TeamMeatEx/TeamMeatEx10/12/16.fnt`: the main text, all languages.
- `font/terminus.fnt` and `font/terminus8.fnt`: the console.
- `font/LuaMiniOutlined.fnt`.
- `font/TeamMeatFont20Bold.fnt`.

Archive lookup ignores case; the files are stored lowercase. **[C]**

- **Duplicate copies.** Where afterbirthp.a and fonts.a both hold a file, the table lists afterbirthp.a's metrics. That afterbirthp.a wins over fonts.a is assumed. **[U]**
- **`font/inconsolata-bold.ttf`** is also in afterbirthp.a; Lua `Font` loads only `.fnt`.
- **Language-folder fonts.** These exist only while that language's archive is active, so mods should not rely on them:
  - `resources.jp/font/mplus_10r|12b`
  - `resources.kr/font/kr_font12|kr_font14|kr_meatfont14`
  - `resources.zh/font/teammeatfontextended10|12|16bold` and `upheavalextended`. These come from the CN patch's archive and have 20945 CJK glyphs each.
- **No `font/teammeatfont10.fnt` or `teammeatfont12.fnt`.** Neither is in the extractor's filelist or among the extracted files. afterbirthp.a still has 43 entries the filelist cannot name. **[U]**

**Recommendation.**
- **Chinese:** `font/cjk/lanapixel.fnt`.
  - The atlas is 13 px tall including its shadow, so line spacing 13 never touches. At 12 (REPENTOGON's choice) the shadow row overlaps the next line's top row by 1 px.
  - It renders ASCII too, so mixed strings need one font.
  - If a needed hanzi is missing, rephrase or use `font/teammeatex/teammeatex10.fnt` (line 16).
  - The one character of the whole official zh column that LanaPixel lacks is 咻.
- **English:** `font/luaminioutlined.fnt`, line 12 (a tighter 9–10 px spacing is safe); its outline reads well over the game. Alternatively the game's own `font/pftempestasevencondensed.fnt`, line 13.

**Draw API in Rep+.** The vanilla `main.lua` redefines `Font:DrawString`:
- The native call is `DrawString(str, x, y, sx, sy, KColor, FontRenderSettings)`.
- The legacy form `DrawString(str, x, y, KColor, boxWidth, center)` goes through `DrawStringScaled`.
- `DrawStringUTF8`, `DrawStringScaledUTF8` and `GetStringWidthUTF8` are legacy aliases; all strings are UTF-8.
- Gotcha: in the legacy wrapper, `boxWidth ~= 0` with `center == false` right-aligns (`x + boxWidth`, `TOP_RIGHT`). The wrapper also leaks the globals `align`, `settings` and `strWidth`.
- `DrawStringAlignment` (`enums.lua`) is TOP/MIDDLE/BOTTOM × LEFT/CENTER/RIGHT, 0–8.
- The exe also has these Font/FontRenderSettings bindings: `GetLineHeight`, `GetBaselineHeight`, `GetCharacterWidth`, `GetStringWidth`, `IsLoaded`, `Load`, `Unload`, `SetMissingCharacter`, `Get/SetMissingCharacterOverride`, `Get/SetLineHeightModifier`, `EnableAutoWrap`, `EnableTruncation`, `Get/SetMaxCharacters`, `Get/SetAlignment`. Which class owns each was not checked. **[U]**

## 4. Reproducing

1. **Set up.** Copy the archives, `tools/ResourceExtractor/ResourceExtractor.exe` and `filelist.txt` into a new `%TEMP%\<dir>`. Lay each archive out as `in_x\resources\packed\<archive>.a`.
2. **Extract.** In that folder, run `.\ResourceExtractor.exe in_x out_x` with relative paths. Redirect stdin from a file holding two newlines, because it waits for ENTER before and after.
   - Files land under `out_x\resources\…` (and `resources.zh\…` for language archives).
   - Entries missing from `filelist.txt` are skipped with "could not determine filename": 43 in afterbirthp.a, 20 in repentance_zh.a.
3. **Generate.** `python3 tools/gen_item_names.py <dir with items.xml and stringtable.sta> mod/isaac_dodge_assist/item_names.lua`
4. **Character set.** `native/tests/data/cjk_font_chars.txt` lists every char id of `lanapixel.fnt`, in code-point order, on one line with no newline. To regenerate it, read block type 4 of the binary .fnt: 20-byte records whose first field is a `uint32` char id.

   ```python
   import struct; b = open('lanapixel.fnt', 'rb').read(); p = 4; ids = []
   while p + 5 <= len(b):
       t, n = b[p], struct.unpack_from('<I', b, p + 1)[0]
       if t == 4: ids += [struct.unpack_from('<I', b, p + 5 + i)[0] for i in range(0, n, 20)]
       p += 5 + n
   open('cjk_font_chars.txt', 'w', encoding='utf-8', newline='').write(''.join(map(chr, sorted(ids))))
   ```

5. **Clean up.** Delete the `%TEMP%` folder.

The game folder is never written. The 2026-10-13 `tools/ResourceExtractor/ResourceExtractor_log.txt` in the game folder comes from an earlier run, not this one.

- `x/out_*`: fonts and atlases.
- `scripts/fnt_info.py`: the BMFont parser.
