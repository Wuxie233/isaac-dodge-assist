## 2. 推荐顺序

```
① Hush + 撒但 ×2 局 ──→ 隐秘出口 + 底片（顺带 Boss Rush）
        │
② 备选路线打 Mother ──→ 雅各和以扫、奇怪的门
        │
③ Home ──→ 红钥匙 → 里角色（联机两人各解一个）→ 之后每趟 Home 都能再解
        
④ 以撒 ×3 → 宝丽来 → 宝箱层 / ???（可以穿插在 ②③ 之间打）
⑤ 穿插：伯大尼、遗骸、游魂、精神错乱、捐款
```

为什么这样排：
- **① 一局两用**。Hush 之后会出通往阴间的活板门（你已经不是第一次打 Hush，不会再出结局箱），所以一局能同时拿到 Hush 和撒但。两局之后，Hush 达到 3 次、撒但达到 5 次，两个大门槛同时解开。
- **② 和 ③ 是里角色的必经之路**。Home 的入口是"奇怪的门"：它要先打过 Mother 才会出现，还要用底片或宝丽来才能打开。所以底片要比宝丽来先拿：底片只差 2 次，还能开暗室，后面的遗骸、游魂都要用到暗室。
- **联机层面也划算**【推论】。wiki 说，联机局里出现什么东西，按"解锁最少的那位玩家"的存档来算。你的好友已经有店主等内容，你很可能就是那份"最少"的存档。比如你没解锁底片和宝丽来，你们的联机局里妈妈就不会掉它们。日志也对得上：10 月以来所有联机局里一次都没掉过。所以先推你的存档，整个联机体验都会变好。

## 3. 每个目标怎么打

### ① Hush + 撒但（2 局，大约 2–4 次尝试）

- **时间线**：妈妈要在 **20:00 内**击败，这样会开 Boss Rush 门（可选，能拿 BR 标记）；它活着！要在 **30:00 内**击败，??? 层的门才会开。超时后离开房间再回来，门就没了。
- **路线**：它活着 → ??? 层（Blue Womb）→ Hush → 走**活板门去阴间（Sheol）** → 撒但。
  - Hush 房里还会出光柱（去大教堂）和虚空门，这两局都不要走。
  - 底片还没解锁时，打完撒但碰箱子就是结局，这局到此为止，这是正常的。
- **选谁**：阿撒泻勒在这条线上的标记已经全拿了，再用他只涨计数，不出新道具。想每局多拿 3–4 个道具，可以换人：

  | 角色 | 这局能拿到 |
  |---|---|
  | 莉莉丝 | Hush → **Incubus（4 级）**；撒但 → Serpent's Kiss；BR → Immaculate Conception；困难心 → Goat Head Baby |
  | 以撒 | 撒但 → **Mom's Knife（4 级）**；BR → Isaac's Head；Hush → Fart Baby；困难心 → Lost Baby |
  | 伊甸（花 1 个币） | Hush → Eden's Blessing；撒但 → Book of Secrets；BR → Undefined |
  | 阿撒泻勒 | 求稳用他：计数照样涨，只是没有新道具 |

- **省时间**：用助手的 F5 地图直奔宝箱房、商店、Boss 房；子宫层找到 Boss 就打，不全清。
- **Hush**：典型的弹幕战。它长时间不受伤会回血，要持续输出；硫磺火打它效果很好。别吃 I'm Drowsy 胶囊：最后阶段的激光是按你的原始速度追的，减速后会跑不掉。

### ② Mother 首杀（前置：隐秘出口；大约 1–3 次）

| 楼层 | 要做的事 |
|---|---|
| 地下室（Basement）I 或 II 的 Boss 打完后 | 出现上锁的门（要 1 把钥匙）→ 下水道（Downpour） |
| 下水道 II | 碰**白色火堆**，你会变成游魂（一碰就死，清完一个房间才变回来）；找有**镜子**的房间穿进去 → 镜像世界的宝箱房里拿 **刀片 1**；再穿镜子回来 |
| 下水道 II 的 Boss 打完后 | 用 2 颗炸弹炸开木板门 → 矿洞（Mines） |
| 矿洞 II | 有刀片 1 才会生成矿车大房间。踩亮 3 个黄色按钮修好轨道 → 坐矿车 → 拿 **刀片 2** → 被 Mother 的影子追，一路跑到出口。这段所有道具都失效，**角色自带的飞行会保留**，阿撒泻勒最轻松 |
| 矿洞 II 的 Boss 打完后 | 陵墓（Mausoleum）门，进门扣 **2 颗完整的心** |
| 陵墓 II | 打陵墓版妈妈（25 分钟内打完还能进 Boss Rush）→ 朝肉门方向射击，刀会飞出去捅开门 → 陵墓版妈妈的心 → 尸宫（Corpse） |
| 尸宫 I / II | 任何伤害都扣 1 整颗心。尸宫 II 的 Boss 是 Mother |

- **带够资源**：至少 1 把钥匙、4 颗以上炸弹，进陵墓时还要剩 2 颗心。
- **选谁**：阿撒泻勒（飞行最适合过矿洞追逐；Mother 首杀给他 Devil's Crown）。好友随意。
- **Mother 怎么打**：二阶段的冲撞最危险。炸弹对她造成 100 点伤害，无视护甲；Chaos Card 只能秒掉一个阶段，建议留给二阶段用。
- **首杀解锁**：雅各和以扫、奇怪的门、挑战 #39 / #40，外加所用角色的 Mother 道具。

### ③ Home → 红钥匙 → 里角色（前置：Mother 已击败，底片已解锁；大约 1–2 次）

1. 这局**走普通的深牢（Depths），不要进陵墓**。深牢 II 的起始房里会有"奇怪的门"。
2. 深牢 II 里一定有一块带标记的骷髅石，炸开会掉 **0 号愚者卡**。
3. 打完妈妈拿底片 → 用愚者卡传回起始房 → 碰奇怪的门（会消耗底片）→ 特殊版陵墓 II → Boss 房里拿**爸爸的字条（Dad's Note）** → 开始上行（Ascent，倒着往回爬，每层都很短）。
4. 到了 Home，**先去妈妈房间打开大箱子**：第一次一定会出**红钥匙**，红钥匙和碎钥匙从此永久解锁。
5. 在通往妈妈卧室的走廊里用红钥匙，打开隐藏衣柜，碰一下里面哭着的角色，就解锁了里角色。
   - **联机**：每个玩家按自己当前角色各解锁一个，人已经死了也算。
   - 但如果**房主自己在玩里角色**，衣柜里就是空的。
6. 然后再睡妈妈的床 → Dogma → 四骑士 → 祸兽（The Beast）。打不过也没关系，前面拿到的解锁不会丢。

- **之后再解锁更多**：每局在宝箱房或 Boss 房丢下 1 个饰品，拿到字条之后它会变成**碎钥匙**，到 Home 里同样能开衣柜。每趟 Home 两人各解锁 1 个里角色。
- **先解哪个**：你想要哪个里角色，这局就用对应的普通角色。
  - 阿撒泻勒 → 里阿撒泻勒：硫磺火加喷嚏，延续你熟悉的玩法。
  - 该隐 → 里该隐：合成袋，很强但很复杂，解锁后还开放挑战 #43。

## 4. 联机注意

- **两个人都从开局就进来**：中途加入的人，这局解锁不了成就。
- **每局之间双方退出大厅重新建**：在同一个大厅里重开，会留下旧的输入帧导致失步（我们 11-04 的排查结论）。
- **标记各记各的**：每人只在自己的存档里拿自己所选角色的标记和成就，中途死了变成幽灵也照样算。你的标记几乎都是困难（联机紫色）。阿撒泻勒那个"普"标记是普通贪婪（Greed）。
- **内容按谁的存档出现**：wiki 的说法是按解锁最少的那份存档（见第 2 节）。但**模式看起来由房主决定**：你自己没解锁 Greedier，却在联机里用莉莉丝打过 Greedier，还拿到了 Duality。想打 Greedier，就让好友开房。
- **捐款对你有效**：11-04 到 11-05 联机期间，你的捐款机计数从 12 涨到了 35。
- **助手模组不影响解锁**：规则是"开着模组时成就禁用，除非已经打过妈妈"。你打过妈妈，日志里也一直在正常解锁。
- **里角色衣柜**：见第 3 节 ③。房主别玩里角色。

## 5. 下一局清单

1. 双方退出大厅，重建一个新的，两人都从开局进来。困难或普通都行，计数都会涨。
2. 选角：你用**莉莉丝**或**以撒**（想求稳就用阿撒泻勒）；好友也挑一个还没打过撒但和 Hush 的角色。
3. 路上看见捐款机就投，再投 15 个就能解锁 There's Options。
4. 妈妈争取在 **20:00 内**打完（进 Boss Rush），它活着！**必须 30:00 内**打完 → 进 ??? 层的门。
5. 打 Hush → 走**活板门（阴间）** → 打撒但 → 进箱子结局。
