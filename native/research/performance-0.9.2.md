## 本轮修改

激光检查在每个候选方向、两种响应模型和每个预测步中重复运行。此前每次线段距离查询都会创建多个引擎 Vector，并重复对各线段开平方；曲线及旋转切片放大了这部分工作。原有压力模拟只覆盖血池和子弹，没有覆盖这条路径。

0.9.2 使用数值坐标计算平方距离，每轮激光快照缓存线段端点与包围盒。只有包围盒间距已不可能优于当前最短距离时，才排除对应线段的精细计算。静止光束的线段在各预测步间共享；旋转光束保留原切片数量、角度和扫掠余量。环形、平移、延迟激活的计算规则保留。

激光采样点、九方向、两种响应模型和预测窗口没有缩减。输入协议与 NativeHost 0.2 不变。

另外补上存活敌方 `EXPLODE` 弹体的 100 单位保守预警；其当前高度或直接碰撞关闭不再阻止这项预警。玩家来源、死亡弹体、普通弹体和爆炸烟排除。该预警低于即时伤害风险，范围沿用保守爆炸包络，并非精确爆炸半径；引爆时机和特殊轨迹尚未建模，可能提前绕行。新增受伤来源的弹体标志、高度、下落速度与加速度记录，用来核对实际漏判。

性能统计仍每 90 次规划输出一次；换房、开始游戏或退出时额外输出尚未记录的剩余样本。`reason` 标明输出原因，`n` 是实际样本数；空缓冲不输出，已输出样本不重复计算。

## 同环境压力模拟

运行实际 `main.lua` 回调，游戏 API 使用 Lua 模拟。房间有 625 个网格；前三组每轮运行 100 次更新，激光组每轮运行 10 次更新。四束激光位于角色附近，长 600 单位；直线各 2 个点，曲线各 16 个点，旋转曲线每逻辑步转动 2 度。

旧版与新版交替运行三轮，下表是三轮每次更新耗时的中位数。Vector 数为完整回调的每次更新分配量，包括扫描与地形部分。

| 场景 | 0.9.1 模拟 ms | 0.9.2 模拟 ms | Vector 数：旧→新 |
| --- | ---: | ---: | ---: |
| 单血池 | 1.740 | 1.674 | 383→383 |
| 200 块血池 | 3.934 | 3.857 | 1,352→1,352 |
| 30 发弹幕 | 3.977 | 4.144 | 712→712 |
| 四条直线激光 | 10.654 | 2.948 | 19,052→386 |
| 四条曲线激光 | 101.667 | 3.889 | 195,340→442 |
| 四条旋转曲线激光 | 425.664 | 12.163 | 771,698→416 |

三组激光模拟耗时分别下降约 72%、96%、97%。非激光场景的变化较小，本轮不据此宣称它们提速；地形 API 调用次数均保持一致。模拟 Vector 是 Lua 对象，不等同于游戏引擎对象，以上耗时与降幅不能换算成 Windows FPS。旋转曲线仍是较重场景，实机收益需加载 0.9.2 后查看日志。

## 检查

- 几何检查涵盖穿越、端点、平行及共线、退化线段、多段曲线、移动源、圆环、旋转、延迟和激活时间。
- 固定种子 920 的 400 个随机形状、19 个时刻，共 7,600 次查询与保存的 0.9.1 几何模块比较，容差为 `1e-8`。
- 三轮六场景各输出 337 条 IAD1 消息。排除序号、时间后，激活标记、角色、窗口、九方向分数和阻挡位全部逐字一致。
- 热路径及首次构建旋转缓存的查询不再创建 Vector；完整回调每次分配小于 2,000，房间 API 调用小于 1,500。
- 短房间统计的回归检查先在旧实现失败，再验证准确均值、峰值、样本数和无重复；实际主模块的换房与退出回调也已覆盖。
- 原有墙体、快速穿越、血池脱困、重叠风险、延迟响应、子弹高度、空场与暂停回归通过。
- 爆炸弹预警用例在旧实现失败；当前实现通过高空/关闭直接碰撞的预警、普通/玩家来源/死亡弹体与爆炸烟排除，以及受伤来源诊断检查。六场景分数一致的结论限于原有压力场景，不包含这项新增行为。
